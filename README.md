# Planqora

Planqora — адаптивное рабочее пространство для управления проектами и задачами.

## Возможности

- обзор активных задач, пространств и прогресса;
- поиск, фильтрация по нескольким категориям и сортировка задач;
- выбранные фильтры в виде удаляемых чипов и пустое состояние поиска;
- канбан-доска со сменой статуса задачи и обновлением колонок;
- детальная страница задачи;
- адаптивные страницы сообщений и настроек;
- skeleton-состояния при переходах между маршрутами;
- отдельная прокрутка контентных областей без прокрутки всей страницы.

## Технологии

- Next.js App Router и React
- TypeScript
- Tailwind CSS
- Radix
- Vitest, React Testing Library и User Event
- ESLint, Prettier и Knip
- pnpm
- Feature-Sliced Design

## Запуск локально

Требования: Node.js 20.9 или новее и pnpm 11.

```bash
pnpm install
pnpm dev
```

После запуска приложение будет доступно по адресу `http://localhost:3000`.

Переменные окружения на текущем этапе не требуются.

## Проверка проекта

```bash
pnpm check
pnpm build
```

Команда `pnpm check` последовательно запускает проверку типов, ESLint, Prettier, тесты и поиск неиспользуемого кода через Knip.

Отдельные команды:

```bash
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test:run
pnpm knip
```

Тестами покрыты чистые функции фильтрации, сортировки, форматирования дат и смены статуса, а также интеграционные пользовательские сценарии списка задач и канбан-доски.

## Дизайн

Интерфейс основан на community-макете [Task Management Dashboard от Pickolab Studio](https://www.figma.com/design/s8uO3S36KuU4o2MBRGhgBM/Task-Management-Dashboard---Pickolab-Studio--Community-?node-id=2-2553). Макет адаптирован под собственную структуру проекта, русскоязычный контент, пространства, канбан-доску и мобильные состояния.
